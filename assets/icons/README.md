# App Icons

This directory contains placeholder app icons. Before submitting to app stores, replace these with professionally designed icons.

## Required Icon Sizes

### iOS
- 1024x1024 - App Store (App Store Connect)
- 512x512 - iTunes (iTunes Connect)
- 256x256 - Spotlight, Settings
- 128x128 - iPhone App Icon (@2x)
- 64x64 - iPhone App Icon (@1x)

### Android
- 512x512 - Google Play Store
- 192x192 - Adaptive Icon
- 144x144 - xxhdpi
- 96x96 - xhdpi
- 72x72 - hdpi
- 48x48 - mdpi

## Creating Icons

Use the following guidelines:
- Use the main icon.svg as a base
- Export to PNG in the required sizes
- Ensure icons are sharp at all sizes
- Follow platform-specific design guidelines:
  - iOS: Human Interface Guidelines
  - Android: Material Design Guidelines

## Tools Recommended
- Sketch
- Figma
- Adobe Illustrator
- GIMP (free alternative)

## Notes
- Current icons are placeholders
- Replace with final assets before app store submission
- Test icons on actual devices for visual consistency
