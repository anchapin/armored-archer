## 🔧 Technical Details

### Color Palettes

**Player Character:**
- Skin: #FFC896
- Hair/Clothing: #8B4513
- Tunic: #228B22
- Accents: Gold, Orange, White

**Enemy Types:**
- Goblin: Forest green
- Skeleton: Bone white/gray
- Shadow Runner: Dark purple
- Brute: Earth brown/tan

**Equipment:**
- Common: Brown/Gray
- Uncommon: Blue/Silver
- Rare: Gold/Yellow
- Legendary: Red/Orange

### File Format Specifications

- **Format:** PNG (lossless)
- **Dimensions:** 32×32 (primary) / 48×48 (equipment)
- **Palette:** 16-color indexed
- **Transparency:** Alpha channel
- **Anti-aliasing:** None (crisp pixels)
- **Compression:** Lossless PNG
