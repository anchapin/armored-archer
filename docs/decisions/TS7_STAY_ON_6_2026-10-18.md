# TypeScript 7 migration assessment (issue #1666)

**Status:** Decided — stay on TypeScript 6.0.3. Revisit when the toolchain
catches up (triggers below).

**Date:** 2026-10-18
**Related:** issue #1666, `.github/dependabot.yml` (TypeScript semver-major
ignore stays in place until revisit)

---

## What was tested

Branch `fix/1666-ts7-assessment` bumped `backend` from `typescript@^6.0.3`
to `typescript@^7.0.2` (npm `latest`) and ran the standard gates:

- `tsc --noEmit` and `tsc -p tsconfig.runtime-contract.json`
- peer-dependency audit of the build/test/lint toolchain

## Findings

**Code-level breakage: minor.** The only `tsc` errors were 9 diagnostics in
`src/utils/eslint-rules/n-plus-one-detection.ts`, all caused by
`@typescript-eslint/utils` losing its top-level hoist under the new install
(it is imported directly but only present transitively via
`eslint-plugin-jsdoc`). Declaring it as an explicit devDependency fixes the
file. No other source errors under TS 7.

**Toolchain breakage: blocking.** Three required devDependencies have no
release that supports TypeScript 7:

| Package | Pinned | Latest available | TypeScript peer range |
| --- | --- | --- | --- |
| `ts-jest` | ^29.4.14 | 29.4.15 | `>=4.3 <7` |
| `typedoc` | ^0.28.20 | 0.28.20 | `… 6.0.x` (no 7.x) |
| `@typescript-eslint/*` (parser, plugin, utils) | ^8.71.2 | 8.71.2 (no v9) | `>=4.8.4 <6.1.0` |

`ts-jest` powers the entire jest suite (154 suites / 4,145 tests) and the
`@typescript-eslint` stack powers the lint and complexity gates. Forcing the
install (`--legacy-peer-deps`) would put CI's required gates on unsupported,
untested combinations — not acceptable for a build-speed improvement.

`ts-loader` (`typescript: *`) and `ts-node` (`>=2.7`) are compatible and not
blockers.

## Decision

**Stay on `typescript@^6.0.3`.** The dependabot semver-major ignore for
TypeScript remains correct and should not be removed yet.

## Revisit triggers

Re-run this assessment when **all three** hold:

1. `ts-jest` publishes a release whose peer range includes TypeScript 7.
2. `@typescript-eslint` publishes a release (v9 or later) supporting TS 7.
3. `typedoc` publishes a release supporting TS 7.

Also worth a re-check when TypeScript 7.1 stabilizes, since early 7.0.x
ecosystem support typically lags the compiler release.
