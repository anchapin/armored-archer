# PRD is a living promises document, not frozen MVP scope

The PRD (`docs/armored-archer_prd.md`) is the source of truth for player-facing *promises* and is amended toward shipped reality when reality has a deliberate paper trail; it was frozen in March 2026 while sprints 1–8 shipped, so several ratified systems (Coins, Gear Rarity, Seasons) existed only in code. We decided: (1) player-facing promises are PRD-wins — contradicting code is a bug; (2) unspecified details are code-wins-by-default; (3) code-invented player-facing concepts must be ratified into the PRD or removed. Amendments land as batched, reviewable diffs, adjudicated by evidence: deliberate evolution (issue/sprint trail) amends the PRD; silent drift gets decided explicitly first.

## Consequences

- Future conflicts resolve via the three rules; "the PRD is outdated" is never itself an argument.
- Ratified 2026-08 session: Coins, Gear Rarity, Season Rewards, Dynamic Difficulty (four constraints), hybrid duel model, power-based punch-up. Superseded: "massive XP bursts" (season rewards), "severe XP penalties" (punch-up loss → Ladder Rating only).
