## 1. PURPOSE

This Alpha User Agreement ("Agreement") governs your participation in the closed

## 2. ALPHA PROGRAM OVERVIEW

### 2.1 What is the Alpha Program?
The Alpha Program is a limited, closed testing phase for a select group of users 
to test the new Go-based backend infrastructure for Armored Archer before its 
public release.

### 2.2 Duration
The Alpha Program is expected to run from **[Start Date]** to **[End Date]** 
(approximately 2-3 weeks). The Developer reserves the right to extend or 
terminate the program at any time.

### 2.3 Your Role
As an Alpha Tester, you will:
- Play Armored Archer using the new Go backend
- Report bugs, issues, and feedback
- Participate in surveys and feedback sessions
- Maintain confidentiality as outlined in this Agreement

## 3. NON-DISCLOSURE OBLIGATIONS

### 3.1 Confidential Information
"Confidential Information" includes, but is not limited to:

- Database schemas and data structures

**Game Content:**
- Unreleased features, mechanics, or systems
- Bug lists and known issues

- Internal communications and documentation
- Access keys and authentication methods

**Business Information:**
- Launch dates and marketing plans
- User statistics and analytics
- Monetization strategies
- Partnership or integration details

### 3.2 Non-Disclosure Obligations
You agree to:

❌ **NOT DISCLOSE** any Confidential Information to third parties  
❌ **NOT POST** screenshots, videos, or streams of alpha gameplay on social media  
❌ **NOT DISCUSS** technical details on forums, Discord (outside alpha channels), or public channels  
❌ **NOT SHARE** access keys, builds, or documentation with others  
❌ **NOT REVERSE ENGINEER** the backend system or attempt to access unauthorized data  
❌ **NOT CREATE** public guides, wikis, or documentation based on alpha experience  

### 3.3 Permitted Disclosures
You MAY:

✅ Discuss gameplay experience with other alpha testers in private alpha channels  
✅ Report bugs and feedback directly to the Developer  
✅ Discuss general impressions after the public release  
✅ Disclose information required by law (with prior notice to Developer)  

### 3.4 Duration of Confidentiality
Your confidentiality obligations under this Agreement shall remain in effect:
- During the Alpha Program
- **Until the official public release of v2.1.0**
- For technical secrets: Indefinitely or until publicly disclosed by Developer
