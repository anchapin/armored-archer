## 2. Competition Analysis

### Competitor Keywords
Based on similar archery/mobile RPG games:

1. **Archery King** - Focus: "archery", "sports", "competition"
2. **Arrow Fest** - Focus: "archery", "casual", "fun"
3. **Modern Archery** - Focus: "archery", "3D", "shooting"

### Gap Analysis
- Most archery games are casual/sports focused
- **Opportunity:** Position as RPG with archery combat
- **Strategy:** Target keywords combining "archery" + "RPG" + "fantasy"

### Recommended Strategy
1. Lead with "archery" - underexplored in RPG space
2. Include "bow" and "shooting" for discoverability
3. Add "rpg", "fantasy", "combat" for genre relevance
4. Include "pvp", "multiplayer" for competitive features

## 4. Google Play Store Keywords

Play Store doesn't have a dedicated keyword field, but keywords should be incorporated into:
- Short description (first 80 characters)
- Full description (natural keyword placement)

### Recommended Short Description
"An epic archery RPG with bow combat & PvP battles"

**Keywords included:** archery, RPG, bow, combat, PvP, battles

## 5. Full Description Optimization

### Recommended Keywords Density
- Primary: archery, archer, bow (3-5 mentions)
- Secondary: rpg, fantasy, combat, battle, pvp (2-3 mentions)
- Tertiary: multiplayer, leaderboard, gear, quest (1-2 mentions)

### Keyword Placement Priority
1. First sentence - critical for indexing
2. First 100 words - high weight
3. Feature bullets - include naturally
4. Throughout description - avoid stuffing
