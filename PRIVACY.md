# Privacy Policy

Last Updated: 2026-03-10

## Overview

Armored Archer is a game application developed and operated by the project team. This privacy policy describes how we collect, use, and protect your information.

## Data Collection

### Game Data
- **Player Profile**: Username, avatar selection, and game preferences
- **Game Progress**: Levels completed, scores, achievements, and in-game statistics
- **Device Information**: Device type, OS version, and performance metrics for optimization

### Online Features
- **Nakama Backend**: Player accounts and authentication via Heroiclabs Nakama
- **Leaderboard**: Player names and scores for competitive rankings
- **Multiplayer**: Match data for PvP and co-op gameplay

## Data Usage

- Provide and improve game services
- Match players for multiplayer sessions
- Display leaderboards and achievements
- Analyze performance for game balancing
- Communicate service announcements

## Data Storage

- Player data is stored on secure Nakama servers
- Authentication tokens are encrypted
- Session data is retained during active play

## Third-Party Services

- **Heroiclabs Nakama**: Backend infrastructure and authentication
- **Analytics**: Anonymous usage analytics for game improvement
- **App Stores**: Platform-specific data handling per store policies

## Children's Privacy

This game is not directed to children under 13. We do not knowingly collect personal information from children.

## Contact

For privacy concerns, contact the development team through the project's GitHub repository.
