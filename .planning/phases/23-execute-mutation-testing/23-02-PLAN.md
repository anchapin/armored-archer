    2. Run mutation history tracking script:

    Expected behavior of track-mutation-history.sh:
    - Gets git info: commit hash, branch name, timestamp
    - Extracts mutation scores for each package
    - Calculates weighted overall mutation score
    - Updates data/coverage-history.json with new entry

    Score extraction process (lines 46-65 of track-mutation-history.sh):
    - Calls run_and_extract_score for each package
    - Runs go-mutesting again to get fresh scores
    - Extracts score with: grep -oP '\d+\.?\d*'
    - Uses 0 as default if extraction fails

    Weighted score calculation (lines 103-115):
    - combat: weight 30
    - matchmaking: weight 30
    - rpg: weight 20
    - store, season, notifications: weight 20/3 each (~6.67)
    - Total weight: 100
    - Formula: sum(score * weight) / total_weight

    Expected new entry in coverage-history.json:
    ```json
    {
      "commit": "abcd1234",
      "branch": "main",
      "date": "2026-03-23T12:34:56Z",
      "mutation_score": {
        "combat": 85.0,
        "matchmaking": 80.0,
        "rpg": 75.0,
        "store": 75.0,
        "season": 75.0,
        "notifications": 75.0,
        "overall": 78.5
      }
    }
    ```

    Expected console output:
    ```
    === Mutation Score History Tracking ===
    Packages: internal/combat internal/matchmaking internal/rpg internal/store internal/season internal/notifications

    Testing package: internal/combat (threshold: 85%)
    Score: 85.0%
    ✓ Score 85.0% meets threshold 85%

    [... other packages ...]

    === Overall Mutation Score: 78.5% ===
    ```
