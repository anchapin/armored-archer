<objective>
Fix the difficulty validation mismatch and add a server-side campaign progress retrieval RPC so the client can sync campaign state across sessions.

Purpose: The client currently sends `difficulty: "normal"` which fails validation (expects easy/medium/hard/nightmare). Additionally, there's no RPC for the client to retrieve its campaign progress from the server — progress only exists locally in `user://campaign_progress.json`. This plan fixes both issues on the backend side.

Output: Updated validation schema, new `get_campaign_progress` RPC handler, registered in index.ts.
</objective>
