# Phase 25 Plan 01: Implement Fixture Mapping Logic

## Objective

Add package-to-fixture mapping function to gap-analysis.sh that automatically suggests test fixtures for packages with coverage gaps.

## Tasks

**Task 1: Add fixture mapping function**
- Extract fixture builder code from fixtures_builder.go
- Create package→fixture mapping in gap-analysis.sh
- Map rpg→NewPlayerBuilder, gear→NewGearBuilder
- Mark unmapped packages as N/A

**Task 2: Update gaps.json structure**
- Add suggested_fixtures array to each gap object
- Populate with fixture names and usage examples
- Update schema documentation

**Task 3: Test fixture mapping**
- Run gap-analysis.sh on test coverage
- Verify gaps.json includes fixture suggestions
- Confirm mapped and unmapped packages handled correctly

## Success Criteria

- gaps.json includes suggested_fixtures arrays
- rpg package shows NewPlayerBuilder() suggestion
- gear package shows NewGearBuilder() suggestion
- Non-fixtured packages marked N/A
- Script runs without errors
