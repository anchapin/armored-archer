<action_details>
1. Create PlayerRatingManager.gd:
   - get_current_rating() retrieves local rating
   - update_rating(opponent_rating, is_win, mode) calculates ELO change
   - get_rating_history() returns progression data
   - get_confidence_interval() for new player uncertainty

2. Create backend player_rating.ts:
   - validate_rating_change() prevents rating manipulation
   - apply_rating_adjustment() updates database
   - get_leaderboard_snapshot() for top players
   - track_match_outcome() for statistics

3. Create database migration:
   - Add player_ratings table
   - Add rating_history table
   - Index on player_id and timestamp

4. Update matchmaking menu:
   - Display player rating
   - Show rating change from previous session
   - Visual indication of rating bracket
</action_details>

<verification_criteria>
- PlayerRatingManager functional on client
- Rating updates after each PvP match
- ELO formula produces reasonable adjustments (±25 for close matches)
- New players gain/lose more points than established players
- Rating displayed in PvP UI
</verification_criteria>
