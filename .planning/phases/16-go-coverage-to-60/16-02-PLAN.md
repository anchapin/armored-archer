# Test Writing Strategy

1. **Focus on high-impact, low-complexity functions first**
   - Pure functions with clear input/output
   - Functions called by critical paths
   - Validation functions

2. **Use table-driven tests for multiple scenarios**
   - Normal cases, edge cases, error cases
   - Cover all branches

3. **Leverage factory fixtures**
   - Use PlayerBuilder for progression tests
   - Use MatchBuilder for matchmaking tests
   - Use GearBuilder for store/inventory tests

4. **Integration tests with testcontainers**
   - Database operations (CRUD)
   - Transaction handling
   - Concurrency scenarios

5. **Keep tests fast and isolated**
   - Use testcontainers for database isolation
   - Clean up after each test
   - Avoid sleep() - use channels or timeouts
