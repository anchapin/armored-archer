1. **Priority scoring:**
   - Critical path packages (combat, matchmaking, rpg): HIGH priority

Update coverage.yml GitHub Actions workflow to integrate enhanced gates and gap analysis:

1. **Add stage-based gate enforcement:**
   - Add job parameter for coverage_gate_stage (default: 1)
   - Run coverage_gates.sh with COVERAGE_GATE_STAGE parameter
   - Fail PR if current stage gate not met

2. **Add gap analysis job:**
   - Run after coverage job completes
   - Execute gap-analysis.sh script
   - Upload gaps.json as workflow artifact
   - Comment on PR with high-priority gaps summary

3. **Enhanced PR comments:**
   - Include current coverage percentage
   - Show current stage and next target
   - List top 5 high-priority zero-coverage functions
   - Provide `make analyze-gaps` command for full list
   - Link to coverage HTML report

4. **Workflow structure:**
   ```yaml
   jobs:
     coverage:
       runs-on: ubuntu-latest
       steps:
         - name: Checkout
           uses: actions/checkout@v4
         - name: Run tests with coverage
           run: |
             cd backend
             go test -coverprofile=coverage/coverage.out -covermode=atomic -coverpkg=./internal/... ./...
         - name: Generate HTML report
           run: |
             cd backend
             go tool cover -html=coverage/coverage.out -o coverage/html/index.html
         - name: Run coverage gates
           run: |
             cd backend/tests/quality
             ./coverage_gates.sh
           env:
             COVERAGE_GATE_STAGE: ${{ github.event.inputs.coverage_stage || '1' }}
         - name: Upload coverage artifacts
           uses: actions/upload-artifact@v4
           with:
             name: coverage-report
             path: backend/coverage/

     gap-analysis:
       runs-on: ubuntu-latest
       needs: coverage
       steps:
         - name: Checkout
           uses: actions/checkout@v4
         - name: Download coverage artifacts
           uses: actions/download-artifact@v4
           with:
             name: coverage-report
         - name: Run gap analysis
           run: |
             cd backend
             bash scripts/gap-analysis.sh
         - name: Upload gaps artifact
           uses: actions/upload-artifact@v4
           with:
             name: coverage-gaps
             path: backend/coverage/gaps.json
         - name: Comment PR with gaps
           if: github.event_name == 'pull_request'
           uses: actions/github-script@v7
           with:
             script: |
               const fs = require('fs');
               const gaps = JSON.parse(fs.readFileSync('backend/coverage/gaps.json', 'utf8'));
               const highPriority = gaps.gaps.filter(g => g.priority === 'HIGH').slice(0, 5);
               const comment = `
                 ## Coverage Report
                 Overall: ${gaps.overall_coverage}%
                 Stage: ${gaps.current_stage}

                 ## High-Priority Gaps (Top 5)
                 ${highPriority.map(g => `- **${g.package}**: ${g.function} (complexity: ${g.complexity})`).join('\n')}

                 Run \`make analyze-gaps\` for full list.
               `;
               github.rest.issues.createComment({
                 issue_number: context.issue.number,
                 body: comment
               });
   ```

5. **Workflow dispatch support:**

   - Useful for testing gates and moving to next stage

6. **Artifact retention:**
