# Integration Test Patterns

Cross-package integration tests should:
1. Test real interactions between systems (not just mocks)
2. Use testcontainers for database isolation
3. Test error scenarios (invalid data, missing dependencies)
4. Test edge cases (boundary conditions, race conditions)
5. Verify data consistency across systems

Example:
```go
func TestIntegration_PlayerWithGear_Stats(t *testing.T) {
    ctx := context.Background()
    db := testhelpers.SetupTestDB(ctx, t)

}
```

# Utility Test Patterns

Utility functions are typically pure functions with clear inputs/outputs:
- Use table-driven tests for multiple scenarios
- Test edge cases (empty inputs, nil values, extreme values)
- Test error cases (invalid parameters, I/O errors)
- Keep tests fast and isolated (no external dependencies)

Example:
```go
func TestCache_Get(t *testing.T) {
    cache := utils.NewCache(5*time.Minute)

    // Test cache miss
    value, found := cache.Get("key1")
    assert.False(t, found)
    assert.Nil(t, value)

    // Test cache hit
    cache.Set("key1", "value1", 1*time.Minute)
    value, found = cache.Get("key1")
    assert.True(t, found)
    assert.Equal(t, "value1", value)
}

func TestCache_TTL(t *testing.T) {
    cache := utils.NewCache(5*time.Minute)

    cache.Set("key1", "value1", 100*time.Millisecond)
    time.Sleep(200*time.Millisecond)

    value, found := cache.Get("key1")
    assert.False(t, found, "Value should expire after TTL")
    assert.Nil(t, value)
}
```
