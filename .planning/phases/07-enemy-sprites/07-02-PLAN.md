  <files>scenes/enemies/base_enemy.gd</files>
  <action>
Update base_enemy.gd with animation handling:

1. Change sprite reference:
   - Old: @onready var sprite: Sprite2D = $Sprite2D
   - New: @onready var animated_sprite: AnimatedSprite2D = $AnimatedSprite2D

2. Add animation state machine functions:
   - _play_animation(animation_name: String) - plays animation with direction suffix
   - update_animation() - selects animation based on priority
   - _update_facing_direction() - determines direction from velocity
   - _on_damaged() - plays hit animation when taking damage
   - _on_died() - plays death animation and handles cleanup

3. Add direction tracking:
   - var facing_direction: Vector2 = Vector2.DOWN

4. Add animation state enum and priority:
   - enum AnimationState { IDLE, WALK, ATTACK, HIT, DEATH }
   - Priority: death > hit > attack > walk > idle

5. Handle animation playback in _physics_process():
   - Call update_animation() based on current velocity and state

6. Remove/modify old sprite.scale code (AnimatedSprite2D handles differently)
  </action>
