# Phase 1: Foundation & Setup

**Duration**: 3 days
**Goal**: Go project structure, build pipeline, and basic modules working in Nakama

---

## Plan 1.1: Go Project Initialization

**Duration**: 4 hours
**AI Writes**: 80%
**Human Reviews**: 20%

### Tasks

1. **Initialize Go Module**
   ```bash
   cd backend
   go mod init github.com/anchapin/armored-archer/backend
   go get github.com/heroiclabs/nakama-sdk-go@v1.0.0
   go get github.com/lib/pq
   ```

2. **Create Directory Structure**
   ```
   backend/
   ├── cmd/
   │   └── server/
   │       └── main.go          # Nakama module entry point
   ├── internal/
   │   ├── config/
   │   ├── database/
   │   ├── rpc/
   │   └── modules/
   ├── pkg/
   │   └── nakama/
   └── tests/
       └── integration/
   ```

3. **Create Go Workspace** (optional, for multi-module)
   ```bash
   go work init
   go work use .
   ```

4. **Add Go Version File**
   ```
   backend/go.mod: go 1.21
   backend/.go-version: 1.21
   ```

5. **Create Makefile Targets**
   ```makefile
   backend-build:
       cd backend && go build -o build/server ./cmd/server
   
   backend-test:
       cd backend && go test ./...
   
   backend-lint:
       cd backend && golangci-lint run
   
   backend-fmt:
       cd backend && go fmt ./...
   ```

### Verification

- [ ] `go mod tidy` completes without errors
- [ ] `go build ./cmd/server` succeeds
- [ ] Directory structure created
- [ ] Makefile targets work

### Success Criteria

- Go module initialized with correct dependencies
- Build command succeeds
- Project structure matches Go conventions

2. **Update docker-compose.yml**
   ```yaml
   nakama:
     volumes:
       - ./build/server:/nakama/data/modules/server.so  # Go shared object
   ```

3. **Update nakama.yml**
   ```yaml
   runtime:
     js_entrypoint: "modules/index.js"  # Keep for now, remove later
   ```

4. **Create Build Script for Go**
   ```bash
   #!/bin/bash
   # backend/build-go.sh
   CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -buildmode=plugin -o build/server.so ./cmd/server
   ```

5. **Test Nakama Loads Go Module**
   ```bash
   docker compose restart nakama
   docker compose logs nakama | grep "Go runtime"
   ```

## Plan 1.3: Configuration & Environment Migration

**Duration**: 6 hours
**AI Writes**: 70%
**Human Reviews**: 30%

### Tasks

1. **Review TypeScript Config Structure**
   ```bash
   # Read existing TypeScript config
   cat backend/src/config/index.ts
   ```

2. **Create Go Config Struct**
   ```go
   // internal/config/config.go
   package config

   type Config struct {
       Server   ServerConfig   `envconfig:"SERVER"`
       Database DatabaseConfig `envconfig:"DATABASE"`
       Session  SessionConfig  `envconfig:"SESSION"`
       RevenueCat RevenueCatConfig `envconfig:"REVENUECAT"`
       Logger   LoggerConfig   `envconfig:"LOGGER"`
       Environment string      `envconfig:"ENVIRONMENT" default:"development"`
   }

   type ServerConfig struct {
       Host       string `envconfig:"HOST" default:"0.0.0.0"`
       Port       int    `envconfig:"PORT" default:"7350"`
       ConsolePort int   `envconfig:"CONSOLE_PORT" default:"7351"`
       Key        string `envconfig:"KEY" default:"defaultkey"`
   }

   // ... other config structs
   ```

3. **Create Config Loader**
   ```go
   func Load() (*Config, error) {
       var cfg Config
       err := envconfig.Process("", &cfg)
       if err != nil {
           return nil, err
       }
       return &cfg, nil
   }
   ```

4. **Migrate Config Validation**
   ```go
   func (c *Config) Validate() error {
       if c.Environment == "production" && c.Server.Key == "defaultkey" {
           return errors.New("NAKAMA_SERVER_KEY must be set in production")
       }
       if c.RevenueCat.PublicKey == "" {
           return errors.New("REVENUECAT_PUBLIC_KEY is required")
       }
       // ... more validation
       return nil
   }
   ```

5. **Update InitModule to Load Config**
   ```go
   var globalConfig *config.Config

   func InitModule(...) error {
       cfg, err := config.Load()
       if err != nil {
           logger.Error("Failed to load config: %v", err)
           return err
       }
       if err := cfg.Validate(); err != nil {
           logger.Error("Config validation failed: %v", err)
           return err
       }
       globalConfig = cfg
       // ... rest of init
   }
   ```

6. **Test Config Loading**
   ```bash
   # Create test
   go test ./internal/config/...
   
   # Verify Nakama starts with config
   docker compose logs nakama | grep -i "config"
   ```

### Verification

- [ ] Config loads from environment variables
- [ ] Validation catches missing required vars
- [ ] Default values applied correctly
- [ ] Config accessible to all modules

### Success Criteria

- Config behavior matches TypeScript implementation
- All environment variables recognized
- Validation errors match TypeScript errors
