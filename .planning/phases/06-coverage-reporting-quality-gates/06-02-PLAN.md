  <action>
    Create scripts/detect-go-flaky-tests.sh with:

    1. Shebang: `#!/bin/bash`
    2. Set: `set -e`, parse arguments: `RUNS=${1:-3}`, `THRESHOLD=${2:-0.33}`
    3. Create data directory: `mkdir -p data`
    4. List all test functions:
       ```bash
       TESTS=$(go test -list . ./... 2>/dev/null | grep "^Test" || true)
       ```
    5. For each test, run N times:
       ```bash
       for test in $TESTS; do
         failures=0
         for i in $(seq 1 $RUNS); do
           if ! go test -run "^${test}$" ./... > /dev/null 2>&1; then
             ((failures++))
           fi
         done
         failure_rate=$(echo "scale=2; $failures / $RUNS" | bc)
       ```
    6. Check if flaky (failure rate >= threshold):
       ```bash
       if (( $(echo "$failure_rate >= $THRESHOLD" | bc -l) )); then
         echo "FLAKY: $test (failure rate: $failure_rate)"
         echo "$test" >> data/go-flaky-tests.txt
       fi
       ```
    7. Output JSON to data/go-flaky-tests.json:
       ```bash
       echo "{\"flaky_tests\": [...], \"timestamp\": \"$(date -u +%Y-%m-%dT%H:%M:%SZ)\", \"runs\": $RUNS, \"threshold\": $THRESHOLD}" > data/go-flaky-tests.json
       ```
    8. Make script executable: `chmod +x scripts/detect-go-flaky-tests.sh`
  </action>

    <automated>test -x scripts/detect-go-flaky-tests.sh && grep -q "failure_rate" scripts/detect-go-flaky-tests.sh && grep -q "go test" scripts/detect-go-flaky-tests.sh</automated>

       ```python
       results = {}
       for i in range(runs):
           proc = subprocess.run(['godot4', '--headless', '--script', 'res://test/run_all_tests.gd'], capture_output=True)
           tree = ET.parse('test/results/gut-results.xml')
           for testcase in tree.findall('.//testcase'):

               if testcase.find('failure') is not None or testcase.find('error') is not None:
       ```

    5. Calculate failure rate and identify flaky tests:
       ```python
       flaky = {}
       for test, failures in results.items():
           rate = failures / runs
           if rate >= threshold:

       ```
    6. Output JSON to data/godot-flaky-tests.json:
       ```python
       with open('data/godot-flaky-tests.json', 'w') as f:
           json.dump({'flaky_tests': flaky, 'timestamp': datetime.datetime.now().isoformat()}, f, indent=2)
       ```
    7. Make script executable: `chmod +x scripts/detect-godot-flaky-tests.py`
  </action>

       ```yaml
                 let goFlaky = [];
       ```
