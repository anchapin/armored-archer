  <action>
    Create scripts/detect-go-flaky-tests.sh with:

    1. Shebang: `#!/bin/bash`
    2. Set: `set -e`, parse arguments: `RUNS=${1:-3}`, `THRESHOLD=${2:-0.33}`
    3. Create data directory: `mkdir -p data`
    4. List all test functions:
       ```bash
       TESTS=$(go test -list . ./... 2>/dev/null | grep "^Test" || true)
       ```
    5. For each test, run N times:
       ```bash
       for test in $TESTS; do
         failures=0
         for i in $(seq 1 $RUNS); do
           if ! go test -run "^${test}$" ./... > /dev/null 2>&1; then
             ((failures++))
           fi
         done
         failure_rate=$(echo "scale=2; $failures / $RUNS" | bc)
       ```
    6. Check if flaky (failure rate >= threshold):
       ```bash
       if (( $(echo "$failure_rate >= $THRESHOLD" | bc -l) )); then
         echo "FLAKY: $test (failure rate: $failure_rate)"
         echo "$test" >> data/go-flaky-tests.txt
       fi
       ```
    7. Output JSON to data/go-flaky-tests.json:
       ```bash
       echo "{\"flaky_tests\": [...], \"timestamp\": \"$(date -u +%Y-%m-%dT%H:%M:%SZ)\", \"runs\": $RUNS, \"threshold\": $THRESHOLD}" > data/go-flaky-tests.json
       ```
    8. Make script executable: `chmod +x scripts/detect-go-flaky-tests.sh`
  </action>

    4. For each flaky test, prepend build tag to test file:
       ```bash
       for test_name in $FLAKY_TESTS; do
           # Find the file containing this test
           TEST_FILE=$(grep -r "func ${test_name}(" backend/ --include="*_test.go" -l | head -1)
           if [ -n "$TEST_FILE" ]; then
               # Check if build tag already exists
               if ! grep -q "//go:build.*flaky" "$TEST_FILE"; then
                   # Prepend build tag to file
                   tmp_file=$(mktemp)
                   echo "//go:build !flaky" > "$tmp_file"
                   echo "// +build !flaky" >> "$tmp_file"
                   echo "" >> "$tmp_file"
                   cat "$TEST_FILE" >> "$tmp_file"
                   mv "$tmp_file" "$TEST_FILE"
                   echo "Quarantined $test_name in $TEST_FILE"
               fi
           fi
       done
       ```
