# Phase 18-01 Plan: RPC Testing Infrastructure Setup

## Objective
Establish the infrastructure needed to test RPC handlers, including a functional `NakamaModule` mock and a session-aware `getUserIDFromContext` helper.

## Tasks

### 1. Create RPC Utils and Enhance Session Retrieval
- Create `backend/internal/rpc/utils.go`.
- Move `getUserIDFromContext`, `checkIfUserIsAdmin`, `pqArray`, `jsonResponse`, and `errorResponse` from `feedback.go` to `utils.go`.
- Update `getUserIDFromContext` to:
  - Check `session.SessionFromContext(ctx)` for user ID.
  - Fallback to placeholder if not found.
- Update `feedback.go` to remove the moved functions (they are in the same package).

### 2. Implement Manual NakamaModule Mock
- Create `backend/tests/testhelpers/mocks/nakama_module_mock.go`.
- Define `TestNakamaModule` struct embedding `runtime.NakamaModule`.
- Implement `StorageRead`, `StorageWrite`, `AccountGet`, `UsersGetId`, `WalletUpdate`, and `NotificationsSend` using function hooks.

### 3. Create RPC Context Helper
- Add `NewTestRPCContext(userID string)` to `backend/tests/testhelpers/context.go` (or similar).
- This helper should return a `context.Context` with `session.SessionInfo` and any required Nakama metadata.

## Success Criteria
- `rpc` package compiles successfully after moving helpers.
- `TestNakamaModule` can be used in a simple test without panic.
- `getUserIDFromContext` returns injected user ID from context.
