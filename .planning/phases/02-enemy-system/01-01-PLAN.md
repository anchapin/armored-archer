# Current Enemy System
From existing code (autoloads/enemy_ai_manager.gd):
- Basic AI state machine (IDLE, PATROL, ATTACK, CHASE, FLINCH, HIT, DEAD)
- Difficulty tiers (EASY, NORMAL, HARD, BOSS) with stat multipliers
- Basic behavior patterns (aggressive, defensive, pack_hunt, ambush)
- Distance-based engagement checks

# Existing Enemy Types
From v3.2.0 Pixel Art milestone:
- 8 enemy types with full sprite animations
- Enemy sprites in assets/sprites/enemies/
- AnimatedSprite2D integration for enemy rendering

# Combat Foundation (Phase 1 Completed)
From Phase 1 deliverables:
- CombatManager with attack timing, damage calculation, hit detection
- AnimationManager with attack animations, hit reactions, damage effects
- Integration tests for combat systems

# Architecture Decisions
- Use EnemyFactory autoload for enemy instantiation (avoids duplicate scene loading code)
- BossManager extends EnemyAIManager but adds phase management and special attacks
- New enemy types inherit from base Enemy class with virtual methods for AI customization
- AI behavior modules in EnemyAIManager for pattern variety
- Boss phases use health percentage thresholds (75%, 50%, 25%)

# Design Decisions
- New enemy types: Elemental (fire/ice/lightning), Flying (harpy-like), Swarmer (small fast rushers)
- Boss types: Guardian (defense-heavy), Warlock (ranged spells), Titan (melee brute)
- AI pattern variety: Aggressive (rush player), Defensive (hold position), Pack-hunting (coordinate attacks), Ambush (hide, then strike)
- Loot tables: Bosses drop Epic/Legendary gear, regular enemies drop Common/Rare
</context>

<specifics>
# New Enemy Types
1. Elemental Enemy:
   - Types: fire_elemental, ice_elemental, lightning_elemental
   - Special: Elemental attacks with damage type (burn, freeze, shock)
   - Weakness: Opposite element deals 2x damage
   - AI Pattern: Cast from distance, dodge when player approaches

2. Flying Enemy:
   - Name: Harpy
   - Movement: Flying with air-to-ground attacks
   - Special: Dive-bomb attack from above
   - AI Pattern: Circle player, dive when cooldown ready

3. Swarmer Enemy:
   - Name: Goblin Rusher
   - Movement: Fast ground movement, group coordination
   - Special: Group buff when 3+ swarmers nearby (speed +20%)
   - AI Pattern: Rush player, flank when possible

# Boss Types
1. Guardian Boss:
   - Name: Stone Guardian
   - Phases: 3 (100% → 75% → 50% → dead)
   - Special Attacks: Ground slam (shockwave), Shield bash (stun)
   - Loot: Legendary armor with +defense stat
   - AI Pattern: Defensive, moves slow, high damage

2. Warlock Boss:
   - Name: Shadow Warlock
   - Phases: 3 with minion spawns at each phase transition
   - Special Attacks: Shadow bolt (projectile), Teleport, Shadow minions
   - Loot: Legendary bow with +attack stat
   - AI Pattern: Ranged, keeps distance, summons minions

3. Titan Boss:
   - Name: Forest Titan
   - Phases: 3 (enrages at 50% health)
   - Special Attacks: Stomp (stun), Roar (fear), Charge
   - Loot: Legendary amulet with +health stat
   - AI Pattern: Aggressive, chases player, high damage

# AI Pattern Behaviors
- Aggressive: 1.5x movement speed, engages at 60% range
- Defensive: 0.8x movement speed, engages at 40% range, holds position
- Pack-hunting: Uses EnemyAIManager to coordinate 2-4 enemies, flanks player
- Ambush: Hides (invisibility or terrain), strikes when player in 30% range
</specifics>
