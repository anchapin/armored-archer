# Phase 20-01 Plan: Bridge Remaining Coverage Gaps

The goal of this plan is to eliminate the final zero-coverage utility packages (`session`, `storage`, `reports`) to prepare for the 60% global coverage target.

## Objectives
- Achieve **85%+ coverage** in `internal/session`.
- Achieve **85%+ coverage** in `internal/storage`.
- Achieve **85%+ coverage** in `internal/reports`.

## Implementation Steps

### 1. Test Session Package
- Create `backend/internal/session/session_test.go`.
- Test `ValidateSessionToken` (empty, invalid, valid formats).
- Test `ValidateSessionExpiry` (using `getTime` override).
- Test `RequireSession` (success/fail).
- Test `ExtractSessionToken` (Bearer, direct, missing).
- Test `IsAdmin` and `RequireAdmin`.
- Test `WithSessionInContext` and `SessionFromContext`.
- Test `ValidateUserOwnership`.

### 2. Test Storage Package
- Create `backend/internal/storage/storage_test.go`.
- Test `MarshalValue` (string, []byte, struct).
- Test `UnmarshalValue` (valid, empty).
- Test `ParseStorageValueJSON` (valid, empty, fallback).
- Test creation helpers (`CreateStorageRead`, `CreateStorageWrite`).

### 3. Test Reports Package
- Create `backend/internal/reports/reports_test.go`.
- Test `SubmitReportRequest.Validate` (all categories, length constraints).
- Test `NewReport` (success, self-report prevention).
- Test `ToJSON`, `FromJSON`, `ReportsToJSON`.
- Test `UpdateStatus` and `IsPending`.
- Test `FilterReportsByStatus` and `GetReportCountByStatus`.

## Testing Strategy
- Pure unit tests for all logic.
- Mock time for session expiry tests.
- Table-driven tests for validations.

## Success Criteria
- [ ] `internal/session` coverage >= 85%.
- [ ] `internal/storage` coverage >= 85%.
- [ ] `internal/reports` coverage >= 85%.
