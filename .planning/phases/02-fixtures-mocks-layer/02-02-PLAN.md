## Tasks

### Task 1: Create builder pattern for fixtures

**Files:** `backend/tests/testhelpers/fixtures_builder.go` (NEW)

**Action:**
Create `fixtures_builder.go` with builder pattern for all fixture types.

Implement **PlayerBuilder**:
- NewPlayerBuilder() - Creates builder with NewTestPlayer() defaults
- WithLevel(level int) - Sets level and auto-scales stats (Attack: 10+level, Defense: 10+level, Dodge: 10+(level/2), CritRate: 5+(level/5))
- WithStats(attack, defense, dodge, critRate int) - Sets custom stats
- WithGear(gear ...TestGear) - Adds gear items to player
- WithID(userID string) - Sets custom user ID
- WithXP(xp int) - Sets player XP
- Build() *TestPlayer - Returns constructed player

Implement **GearBuilder**:
- NewGearBuilder() - Creates builder with NewTestGear() defaults
- WithType(gearType string) - Sets gear type (helm, armor, bow, arrow, amulet)
- WithRarity(rarity string) - Sets rarity (common, rare, epic, legendary) and scales base stats
- WithStats(attack, defense, dodge, critRate int) - Sets custom stats
- WithID(id string) - Sets custom gear ID
- WithDisplayName(name string) - Sets display name
- Build() *TestGear - Returns constructed gear

Implement **MatchBuilder**:
- NewMatchBuilder() - Creates builder with NewTestMatch() defaults
- WithPlayers(creatorID, opponentID string) - Sets player IDs
- WithStatus(status string) - Sets match status
- WithHealth(creatorHealth, opponentHealth int) - Sets health values
- WithTurn(turn int) - Sets current turn
- WithID(matchID string) - Sets custom match ID
- Build() *TestMatch - Returns constructed match

All builder methods must return *Builder for chaining.

### Task 2: Add JSON serialization to fixtures

**Files:** `backend/tests/testhelpers/fixtures.go` (MODIFY)

**Action:**
Add JSON serialization methods to existing TestPlayer, TestGear, TestMatch structs.

Add methods to each struct:
- toJSON() string - Serializes fixture to JSON string
- fromJSON(jsonStr string) error - Deserializes JSON into fixture (receiver must be pointer)
- MarshalJSON() []byte - Implements json.Marshaler interface
- UnmarshalJSON([]byte) error - Implements json.Unmarshaler interface

Example for TestPlayer:
```go
func (p *TestPlayer) toJSON() string {
    bytes, _ := json.Marshal(p)
    return string(bytes)
}

func (p *TestPlayer) fromJSON(jsonStr string) error {
    return json.Unmarshal([]byte(jsonStr), p)
}
```

Handle time.Time formatting using RFC3339 for CreatedAt fields.

**Verify:**
```bash
go test ./backend/tests/testhelpers/... -run TestJSONSerialization -v
```

Expected: Fixtures can be serialized to JSON and deserialized back without data loss.

**Done:**
All fixture types have toJSON/fromJSON methods, JSON round-trip works correctly, time fields are preserved.
