## Interface Design Decisions

### Database Interface

**Methods:**
- `QueryContext(ctx context.Context, query string, args ...interface{}) (*sql.Rows, error)`
- `QueryRowContext(ctx context.Context, query string, args ...interface{}) *sql.Row`
- `ExecContext(ctx context.Context, query string, args ...interface{}) (sql.Result, error)`
- `BeginTx(ctx context.Context, opts *sql.TxOptions) (*sql.Tx, error)`
- `Close() error`

**Rationale:**
- Minimal interface following Interface Segregation Principle
- Only includes methods currently used by DBWrapper
- Context-aware methods for timeout/cancellation support
- Transaction support for complex operations

### Logger Interface

**Methods:**
- `Info(format string, args ...interface{})`
- `Debug(format string, args ...interface{})`
- `Warn(format string, args ...interface{})`
- `Error(format string, args ...interface{})`

**Rationale:**
- Extracted from Nakama's runtime.Logger
- Minimal set of logging methods used in RPC handlers
- Enables testing of logging behavior without Nakama dependency

## Mock Generation

### Commands

Generate Database mock:
```bash
mockgen -source=backend/internal/database/database.go \
  -destination=backend/tests/testhelpers/mocks/database_mock.go \
  -package=mocks
```

Generate Logger mock:
```bash
mockgen -source=backend/internal/runtime/nakama.go \
  -destination=backend/tests/testhelpers/mocks/logger_mock.go \
  -package=mocks
```

### Automation

**Makefile target:**
```bash
make generate-mocks
```

Features:
- Auto-installs mockgen if not present
- Regenerates all mocks from interfaces
- Idempotent (can run multiple times safely)
- Provides clear success/error messages

## Mock Usage Examples

### Basic Database Mock

```go
ctrl := gomock.NewController(t)
defer ctrl.Finish()

mockDB := mocks.NewMockDatabase(ctrl)

mockDB.EXPECT().
    ExecContext(gomock.Any(), gomock.Eq("INSERT INTO players..."), gomock.Any()).
    Return(&mockResult{lastInsertID: 1, rowsAffected: 1}, nil)

_, err := mockDB.ExecContext(ctx, "INSERT INTO players...", "player123", "TestPlayer")
require.NoError(t, err)
```

### Basic Logger Mock

```go
ctrl := gomock.NewController(t)
defer ctrl.Finish()

mockLogger := mocks.NewMockLogger(ctrl)

mockLogger.EXPECT().Info(gomock.Eq("Player created: %s"), gomock.Any()).Times(1)
mockLogger.EXPECT().Debug(gomock.Any()).AnyTimes()
mockLogger.EXPECT().Warn(gomock.Any()).AnyTimes()
mockLogger.EXPECT().Error(gomock.Any()).AnyTimes()

mockLogger.Info("Player created: %s", "player123")
```

### RPC Handler Pattern

```go
func TestPlayerService_CreatePlayer(t *testing.T) {
    ctrl := gomock.NewController(t)
    defer ctrl.Finish()

    mockDB := mocks.NewMockDatabase(ctrl)
    mockLogger := mocks.NewMockLogger(ctrl)

    mockDB.EXPECT().ExecContext(ctx, gomock.Any(), gomock.Any(), gomock.Any()).
        Return(&mockResult{lastInsertID: 1, rowsAffected: 1}, nil)
    mockLogger.EXPECT().Info(gomock.Eq("Creating player: %s"), gomock.Eq(playerID))

    // RPC handler logic
    mockLogger.Info("Creating player: %s", playerID)
    _, err := mockDB.ExecContext(ctx, "INSERT INTO players...", playerID, playerName)

    require.NoError(t, err)
}
```
