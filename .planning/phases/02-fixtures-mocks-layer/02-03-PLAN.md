### Task 1: Extract Database interface from implementation

**Files:** `backend/internal/database/database.go` (NEW or MODIFY)

**Action:**
Examine existing database layer code and extract a minimal Database interface.

First, locate the database implementation:
```bash
find backend -name "*.go" -type f | xargs grep -l "sql.DB\|database/sql" | head -5
```

Then extract interface with these methods:
- QueryContext(ctx context.Context, query string, args ...interface{}) (*sql.Rows, error)
- QueryRowContext(ctx context.Context, query string, args ...interface{}) *sql.Row
- ExecContext(ctx context.Context, query string, args ...interface{}) (sql.Result, error)
- BeginTx(ctx context.Context, opts *sql.TxOptions) (*sql.Tx, error)
- Close() error

If existing code uses a concrete type (e.g., *sql.DB directly), create DBWrapper struct that wraps *sql.DB and implements Database interface.

Add compile-time check:
```go
// Ensure DBWrapper implements Database interface
var _ Database = (*DBWrapper)(nil)
```

Keep implementation minimal - only extract what's needed for current tests. Follow Interface Segregation Principle.

Reference: RESEARCH.md lines 258-295 for interface extraction pattern.

**Verify:**
```bash
go build ./backend/internal/database/
```

Expected: Code compiles, Database interface exists, DBWrapper implements it.

**Done:**
Database interface extracted, DBWrapper implements interface, compile-time check passes.

### Task 3: Generate mocks using uber-go/mock

**Files:** `backend/tests/testhelpers/mocks/database_mock.go` (NEW), `backend/tests/testhelpers/mocks/nakama_runtime_mock.go` (NEW), `backend/tests/testhelpers/mocks/logger_mock.go` (NEW)

**Action:**
Generate mocks from extracted interfaces using mockgen.

First, install mockgen CLI:
```bash
go install go.uber.org/mock/mockgen@latest
```

Generate Database mock:
```bash
mockgen -source=backend/internal/database/database.go \
  -destination=backend/tests/testhelpers/mocks/database_mock.go \
  -package=mocks
```

Generate Nakama runtime mocks:
```bash
mockgen -source=backend/internal/runtime/nakama.go \
  -destination=backend/tests/testhelpers/mocks/nakama_runtime_mock.go \
  -package=mocks
```

If mocking vendor Nakama interfaces directly:
```bash
mockgen -source=vendor/github.com/heroiclabs/nakama-common/runtime/go.mod \
  -destination=backend/tests/testhelpers/mocks/nakama_runtime_mock.go \
  -package=mocks
```

Ensure generated mocks have:
- Mock struct (e.g., MockDatabase)
- NewMock function (e.g., NewMockDatabase)
- EXPECT() method returning recorder
- All interface methods mocked

### Task 4: Add Makefile target for mock regeneration

**Files:** `Makefile` (MODIFY)

**Action:**
Add `generate-mocks` target to Makefile for automated mock regeneration.

Add target:
```makefile
# Generate mocks from interfaces using mockgen
.PHONY: generate-mocks
generate-mocks:
	@echo "Generating mocks..."
	mockgen -source=backend/internal/database/database.go \
		-destination=backend/tests/testhelpers/mocks/database_mock.go \
		-package=mocks
	mockgen -source=backend/internal/runtime/nakama.go \
		-destination=backend/tests/testhelpers/mocks/nakama_runtime_mock.go \
		-package=mocks
	@echo "Mocks generated successfully"
```

Add to help target if exists:
```makefile
help:
	@echo "Available targets:"
	@echo "  generate-mocks    - Generate mocks from interfaces"
```

Ensure target is idempotent (can run multiple times safely).

**Verify:**
```bash
make generate-mocks
```

Expected: Mocks are regenerated, no errors, files are updated.

**Done:**
Makefile has generate-mocks target, running it regenerates all mocks successfully.

### Task 5: Create mock usage example test

**Files:** `backend/tests/integration/mocks_example_test.go` (NEW)

**Action:**
Create example test demonstrating mock usage for RPC handlers.

Test should:
1. Create gomock.Controller
2. Create mock database and mock logger
3. Set up expectations using EXPECT() chain
4. Use mocks in RPC handler or service
5. Verify expectations are met

Example:
```go
func TestPlayerService_CreatePlayer(t *testing.T) {
    ctrl := gomock.NewController(t)
    defer ctrl.Finish()

    mockDB := mocks.NewMockDatabase(ctrl)
    mockLogger := mocks.NewMockNakamaLogger(ctrl)

    mockDB.EXPECT().
        ExecContext(gomock.Any(), gomock.Any(), gomock.Any()).
        Return(sql.Result{}, nil)

    mockLogger.EXPECT().Info(gomock.Any()).AnyTimes()

    service := NewPlayerService(mockDB, mockLogger)
    err := service.CreatePlayer(ctx, player)

    require.NoError(t, err)
}
```

Use testify/assert and testify/require for assertions.

Reference: RESEARCH.md lines 401-420 for mock usage pattern.
