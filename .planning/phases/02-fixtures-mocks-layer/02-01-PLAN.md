### Task 2: Implement testcontainers PostgreSQL setup/teardown

**Files:** `backend/tests/testhelpers/db_testcontainers.go` (NEW)

**Action:**
Create `db_testcontainers.go` with testcontainers PostgreSQL setup, following the research pattern exactly.

Implement:
1. **TestDB struct** with fields: Container (*postgres.PostgresContainer), DB (*sql.DB), ConnStr (string), Snapshot (string)
2. **SetupTestDB function** that:
   - Creates PostgreSQL container using `postgres.Run()`
   - Uses postgres 16-alpine image
   - Configures database: "test_db", user: "test_user", password: "test_password"
   - Loads migrations from `backend/data/migrations/` via `WithInitScripts()`
   - Waits for log "database system is ready to accept connections" (occurrence 2, 5s timeout)
   - Opens database connection
   - Creates initial snapshot for fast reset
   - Returns *TestDB
3. **TeardownTestDB function** that:
   - Closes database connection
   - Terminates PostgreSQL container
   - Returns error if cleanup fails
4. **ResetTestDB function** that:
   - Restores database to initial snapshot
   - Returns error if restore fails

Use context.Context throughout for cancellation support.

Reference: `/home/alex/armored-archer/.planning/phases/02-fixtures-mocks-layer/02-RESEARCH.md` lines 73-164 for exact implementation pattern.

**Verify:**
```bash

```

Expected: File compiles, no import errors, TestDB struct and functions exist.

**Done:**
`db_testcontainers.go` exists with all four components (TestDB, SetupTestDB, TeardownTestDB, ResetTestDB), code compiles without errors.
