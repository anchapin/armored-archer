# Alpha User Onboarding Checklist

**Version**: 1.0  
**Created**: 2026-03-16  
**For**: Armored Archer v2.1.0 Alpha Testing Program  
**Owner**: Development Team / Community Manager

---

## 📋 Overview

This checklist ensures consistent and complete onboarding for all alpha testers. 
Use this to track each user's progress through the onboarding process.

---

## 🎯 Onboarding Goals

By the end of onboarding, every alpha user should:

1. ✅ Understand their role and responsibilities
2. ✅ Have signed the NDA/Alpha User Agreement
3. ✅ Have redeemed their access key
4. ✅ Have joined Discord and received Alpha Tester role
5. ✅ Have accessed and read the Alpha User Guide
6. ✅ Know how to report bugs and provide feedback
7. ✅ Have completed their first test session

---

Quick start guide:
1. Launch Armored Archer
2. You should see an "Alpha" badge in the menu
3. Jump into a match as you normally would!

Having issues? Common fixes:
- Restart the game after redeeming your key
- Check #alpha-known-issues for any outages
- Ask for help in #alpha-support

Your feedback matters - even if it's just "hey, this feels off!" 

Let me know if I can help with anything. 🚀

## 🔧 Technical Verification Checklist

### For Each User

- [ ] **Database record created**
  - Table: alpha_users
  - Fields verified: access_key, status, tier, expires_at

- [ ] **Discord role assigned**
  - Role: Alpha Tester
  - Permissions verified
  - Channel access confirmed

- [ ] **Authentication working**
  - Can login to alpha environment
  - Session persists correctly
  - No authentication errors

- [ ] **Matchmaking working**
  - Can find matches
  - Matched with other alpha users only
  - Queue times reasonable (< 2 min)

- [ ] **Analytics tracking**
  - User ID logged in analytics
  - Events firing correctly
  - Dashboard showing data
