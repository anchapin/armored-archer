## Tasks

### Task 1: Create core 60 FPS gameplay test

**Files:** `test/suites/performance/test_60fps_gameplay_loops.gd` (NEW)

**Read First:**
- `test/suites/performance/test_performance_benchmarks.gd` - Reference existing performance test patterns
- `autoloads/GameManager.gd` - Understand GameManager interface and _process pattern
- `autoloads/PerformanceProfiler.gd` - Understand FPS tracking and frame time measurement

**Action:**
Create `test_60fps_gameplay_loops.gd` extending GutTest with comprehensive 60 FPS validation tests.

Implement test_core_gameplay_60_fps:

1. **Setup** - Create GameManager instance and add_child_autofree for cleanup
2. **FPS sampling** - Simulate 60 seconds of gameplay (3600 frames at 60 FPS)
   - In each frame: Call game_manager._process(1.0 / 60.0) and game_manager._physics_process(1.0 / 60.0)
   - Collect FPS samples via Engine.get_frames_per_second() or PerformanceProfiler
   - Use await wait_for_physics_frame() to advance the simulation
3. **Validation** - Calculate average FPS and assert:
   - Average FPS >= 55 (allowing 5 FPS margin for test environment variance)
   - Minimum FPS > 30 (no severe frame drops below playable threshold)
   - Frame time P95 < 20ms (95% of frames complete within 20ms)

Use GUT assertions:
- assert_gt(avg_fps, 55.0, "Average FPS should be >= 55 (target: 60)")
- assert_gt(min_fps, 30.0, "Minimum FPS should be > 30")

**Verify:**
```bash
godot4 --headless --script test/suites/performance/test_60fps_gameplay_loops.gd
```

Expected: Test runs to completion, all assertions pass, output shows average FPS >= 55.

**Done:**
test_60fps_gameplay_loops.gd exists with test_core_gameplay_60_fps function that validates 60 FPS target.

### Task 5: Configure V-Sync disabled for accurate performance measurement

**Files:** `project.godot` (MODIFY)

**Action:**
Ensure V-Sync is disabled for performance tests to prevent artificial FPS capping at monitor refresh rate.

Add or modify in project.godot:
```ini
[display]

window/stretch/mode="viewport"
window/size/viewport_width=1920
window/size/viewport_height=1080
window/size/resizable=false
window/vsync/use_vsync=false
```

If use_vsync is already set to false, no change needed. If set to true, change to false.

**Verify:**

Expected: use_vsync=false is set in project.godot.
