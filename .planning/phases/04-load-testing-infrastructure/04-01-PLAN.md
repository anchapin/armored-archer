**Files:** `backend/internal/rpc/rpc_bench_test.go` (MODIFY - implements Wave 0 stubs)

**Action:**
Implement the benchmark functions in `rpc_bench_test.go`, replacing the Wave 0 stubs with full implementations.

Implement benchmarks:

1. **BenchmarkGetPlayerStats** - Measures performance of GetPlayerStats RPC handler
   - Setup: Create testcontainers PostgreSQL instance via testhelpers.SetupTestDB
   - Insert test player stats row with realistic data (level=10, experience=5000, stats JSON)
   - Use b.ResetTimer() to exclude setup time from measurement
   - Loop: Call GetPlayerStats with mock logger, nk, and "{}" payload
   - Expect: Database query completes, stats JSON is parsed and returned

2. **BenchmarkGetLeaderboard** - Measures performance of GetLeaderboard RPC handler
   - Setup: Create testcontainers PostgreSQL, insert 100 test players with varying XP
   - ResetTimer to exclude setup
   - Loop: Call GetLeaderboard with limit=100, offset=0
   - Expect: JOIN query with users table, 100 rows returned

3. **BenchmarkGetInventory** - Measures performance of GetInventory RPC handler
   - Setup: Create testcontainers PostgreSQL, insert test user with 20 gear items
   - Include catalog entries with realistic JSON (base_stats, modifiers)
   - ResetTimer to exclude setup
   - Loop: Call GetInventory with test user ID
   - Expect: JOIN with catalog table, JSON parsing for each item

4. **BenchmarkGetPlayerStatsParallel** - Measures concurrent performance
   - Setup: Create testcontainers PostgreSQL with test player
   - Use b.RunParallel() to simulate concurrent access
   - Loop: Each goroutine calls GetPlayerStats
   - Expect: Database connection pool handles concurrent requests

Use testify/mock for logger and NakamaModule interfaces. Create minimal mocks that satisfy the interface without expensive operations.

**Verify:**
```bash
cd backend && go test -bench=BenchmarkGetPlayerStats -benchmem -run=^$ ./internal/rpc/
cd backend && go test -bench=BenchmarkGetLeaderboard -benchmem -run=^$ ./internal/rpc/
cd backend && go test -bench=BenchmarkGetInventory -benchmem -run=^$ ./internal/rpc/
cd backend && go test -bench=BenchmarkGetPlayerStatsParallel -benchmem -run=^$ ./internal/rpc/
```

Expected: All benchmarks run successfully (not skipped), output includes ns/op, B/op, allocs/op metrics.

**Done:**
`rpc_bench_test.go` contains 4 implemented benchmarks, all run successfully and produce performance metrics.
