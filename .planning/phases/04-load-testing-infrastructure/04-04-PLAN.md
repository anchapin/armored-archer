### Task 1: Create compare.sh script for benchmark comparison

**Files:** `backend/tests/benchmarks/compare.sh` (NEW)

**Read First:**
- `backend/tests/benchmarks/baseline.txt` - Read baseline file format
- No existing compare.sh - this is new

**Action:**
Create `compare.sh` shell script that uses benchstat to compare benchmark results against baseline.

Implement:

1. **Shebang and set -e** - Ensure script exits on errors:
   ```bash
   #!/bin/bash
   set -e
   ```

2. **Install benchstat** - Install the official Go benchmark comparison tool:
   ```bash
   echo "Installing benchstat..."
   go install golang.org/x/perf/cmd/benchstat@latest
   ```

3. **Compare results** - Run benchstat with baseline and new results:
   ```bash
   echo "Comparing benchmark results..."
   benchstat baseline.txt new.txt
   ```

4. **Check for regression** - Parse benchstat output for regressions > 10%:
   ```bash
   # Check if any benchmark shows >10% regression (indicated by ~ in output)
   if benchstat baseline.txt new.txt | grep "~" | grep -q "+[1-9][0-9]\.%"; then
     echo "Performance regression detected!"
     exit 1
   fi
   ```

5. **Save comparison** - Save benchstat output to file:
   ```bash
   benchstat baseline.txt new.txt > comparison.txt
   cat comparison.txt
   ```

6. **Update baseline** - Function to update baseline (called on main branch):
   ```bash
   update_baseline() {
     cp new.txt baseline.txt
     echo "Baseline updated"
   }
   ```

Make script executable with proper permissions.

**Verify:**
```bash
chmod +x backend/tests/benchmarks/compare.sh
cd backend && go test -bench=. -benchmem -run=^$ ./internal/rpc/... > tests/benchmarks/new.txt
cd backend/tests/benchmarks && ./compare.sh
```

Expected: Script runs benchstat, shows comparison, exits 0 if no regression, exits 1 if regression detected.

**Done:**
compare.sh exists with benchstat installation, comparison logic, regression detection, and baseline update function.

### Task 2: Create GitHub Actions workflow for benchmark regression detection

**Files:** `.github/workflows/benchmark-regression.yml` (NEW)

**Read First:**
- `.github/workflows/ci.yml` - Read existing workflow patterns for Go setup and checkout
- `backend/tests/benchmarks/compare.sh` - Understand comparison script usage

**Action:**
Create `benchmark-regression.yml` workflow that runs on every PR and push to main.

Implement:

1. **Trigger conditions** - Run on PR to main/develop and push to main:
   ```yaml
   on:
     pull_request:
       branches: [ main, develop ]
     push:
       branches: [ main ]
   ```

2. **Permissions** - Allow contents write for baseline updates:
   ```yaml
   permissions:
     contents: write
   ```

3. **Benchmark job** - Single job with multiple steps:
   ```yaml
   jobs:
     benchmark:
       runs-on: ubuntu-latest
       steps:
   ```

4. **Checkout step** - Fetch full history for baseline comparison:
   ```yaml
   - name: Checkout code
     uses: actions/checkout@v4
     with:
       fetch-depth: 0
   ```

5. **Setup Go** - Use Go 1.21+:
   ```yaml
   - name: Setup Go
     uses: actions/setup-go@v5
     with:
       go-version: '1.21'
   ```

6. **Run benchmarks** - Execute Go benchmarks and save results:
   ```yaml
   - name: Run benchmarks
     run: |
       cd backend
       go test -bench=. -benchmem -run=^$ ./internal/rpc/... > tests/benchmarks/new.txt
   ```

7. **Fetch baseline** - Get baseline from main branch:
   ```yaml
   - name: Fetch baseline
     run: |
       cd backend/tests/benchmarks
       git checkout origin/main -- baseline.txt || echo "No baseline found, using new results as baseline"
   ```

8. **Compare results** - Run compare.sh:
   ```yaml
   - name: Compare with baseline
     run: |
       cd backend/tests/benchmarks
       chmod +x compare.sh
       ./compare.sh
     continue-on-error: true
   ```

9. **Fail on regression** - Check for regression and fail if detected:
   ```yaml
   - name: Fail on regression
     run: |
       if grep -q "Performance regression detected" backend/tests/benchmarks/comparison.txt; then
         echo "Performance regression detected! Failing check."
         exit 1
       fi
   ```

10. **Update baseline on main** - Commit new baseline on main branch:
   ```yaml
   - name: Update baseline on main
     if: github.ref == 'refs/heads/main'
     run: |
       cd backend/tests/benchmarks
       cp new.txt baseline.txt
       git config user.name "github-actions[bot]"
       git config user.email "github-actions[bot]@users.noreply.github.com"
       git add baseline.txt
       git commit -m "chore: update performance baseline"
       git push
   ```

11. **Upload results** - Save benchmark results as artifacts:
   ```yaml
   - name: Upload benchmark results
     uses: actions/upload-artifact@v4
     with:
       name: benchmark-results
       path: |
         backend/tests/benchmarks/new.txt
         backend/tests/benchmarks/comparison.txt
       retention-days: 30
   ```

**Verify:**
```bash
# Manual verification: Run workflow locally using act
cat .github/workflows/benchmark-regression.yml
```

Expected: YAML is valid, contains all steps, permissions are correct.

**Done:**
benchmark-regression.yml exists with all steps, runs on PR/push, compares benchmarks, fails on regression, updates baseline.

### Task 3: Add Make target for running benchmarks

**Files:** `Makefile` (MODIFY)

**Read First:**
- `Makefile` - Read existing test and backend targets

**Action:**
Add `benchmark` target to Makefile for local benchmark execution.

Add to .PHONY line:
```makefile
.PHONY: ... benchmark
```

Add target:
```makefile
benchmark:
	@echo "$(BLUE)Running Go benchmarks...$(RESET)"
	cd $(BACKEND_DIR) && go test -bench=. -benchmem -run=^$$ ./internal/rpc/...
```

Add `benchmark-compare` target:
```makefile
benchmark-compare:
	@echo "$(BLUE)Running benchmarks and comparing to baseline...$(RESET)"
	cd $(BACKEND_DIR) && go test -bench=. -benchmem -run=^$$ ./internal/rpc/... > tests/benchmarks/new.txt
	cd $(BACKEND_DIR)/tests/benchmarks && chmod +x compare.sh && ./compare.sh
```

Add `benchmark-update` target:
```makefile
benchmark-update:
	@echo "$(BLUE)Updating performance baseline...$(RESET)"
	cd $(BACKEND_DIR) && go test -bench=. -benchmem -run=^$$ ./internal/rpc/... > tests/benchmarks/baseline.txt
	@echo "$(GREEN)Baseline updated$(RESET)"
```

Add help text:
```makefile
@echo "  make benchmark         Run Go benchmarks"
@echo "  make benchmark-compare Run benchmarks and compare to baseline"
@echo "  make benchmark-update  Update performance baseline"
```

**Verify:**
```bash
grep -A2 "benchmark:" Makefile
```

Expected: Makefile contains three new targets (benchmark, benchmark-compare, benchmark-update) with help text.

**Done:**
Makefile updated with benchmark targets, developer can run benchmarks via make.
