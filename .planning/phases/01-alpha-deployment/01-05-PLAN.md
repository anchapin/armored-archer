- Security vulnerability discovered

2. Restore TypeScript module

4. Restart Nakama
5. Verify functionality

## Rollback Time Estimate
- Module rollback: 5 minutes
- Database rollback: 15-30 minutes
- Total: 20-35 minutes

### Task 1.5.5: Automated Rollback Script

**What**: Create rollback automation script

```bash
#!/bin/bash
# scripts/rollback-alpha.sh

set -e

echo "Starting rollback procedure..."

# Stop Nakama
echo "Stopping Nakama..."
sudo systemctl stop nakama

# Restore TypeScript module
echo "Restoring TypeScript module..."
cp /opt/nakama/backup/server.ts /opt/nakama/modules/server

# Restore config
echo "Restoring configuration..."
cp /opt/nakama/backup/config.yml /etc/nakama/config.yml

# Start Nakama
echo "Starting Nakama..."
sudo systemctl start nakama

# Verify
echo "Verifying Nakama..."
sleep 5
curl -f http://localhost:7350/health || exit 1

echo "Rollback completed successfully!"
```

- [ ] Create rollback script
- [ ] Test rollback script on staging
- [ ] Make script executable
- [ ] Store in accessible location
- [ ] Document script usage
