    1. Shebang and setup: `#!/bin/bash set -e`

    2. Git info extraction (same pattern as track-coverage-history.sh):
       - COMMIT=$(git rev-parse --short HEAD)
       - BRANCH=$(git rev-parse --abbrev-ref HEAD)
       - DATE=$(date -u +%Y-%m-%dT%H:%M:%SZ)

    3. Mutation score extraction from go-mutesting output:
       - Run go-mutesting on packages and capture output to temp file
       - Parse "The mutation score is X.XXXXXXX" for each package
       - Extract scores:
         - combat_score from internal/combat output
         - matchmaking_score from internal/matchmaking output
         - rpg_score from internal/rpg output
         - store_score from internal/store output
         - season_score from internal/season output
         - notifications_score from internal/notifications output
         - Calculate overall mutation_score as weighted average:
           - combat: 30% weight
           - matchmaking: 30% weight
           - rpg: 20% weight
           - store, season, notifications: 20% combined weight

    4. Threshold checking (from mutation_config.yaml):
       - Compare each package score against threshold
       - Log warnings for packages below threshold
       - Exit 1 if critical packages (combat, matchmaking) below threshold

    5. Update data/coverage-history.json:
       - Check if file exists, create if not
       - Use jq to update latest history entry with mutation_score field:
         ```json
         {
           "commit": "$COMMIT",
           "branch": "$BRANCH",
           "date": "$DATE",
           "mutation_score": {
             "combat": 85.0,
             "matchmaking": 80.0,
             "rpg": 75.0,
             "store": 75.0,
             "season": 75.0,
             "notifications": 75.0,
             "overall": 78.5
           }
         }
         ```
       - If updating existing entry, append new entry with existing fields preserved
       - Keep only last 30 entries to manage file size

    6. Trend analysis output:
       - Show last 5 mutation scores with date comparison
       - Highlight regressions (score decrease > 5%)
       - Show improvement (score increase)
       - Display trend arrow: ↗ up, ↘ down, → stable

    7. Flaky test quarantine respect:
       - Check data/flaky-test-quarantine.json
       - Skip quarantined tests during mutation score calculation
       - Document quarantined tests in report output

    Make executable: `chmod +x scripts/track-mutation-history.sh`

    Reference track-coverage-history.sh for jq patterns and history management.
  </action>
