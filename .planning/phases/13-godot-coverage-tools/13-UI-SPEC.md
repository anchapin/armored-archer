## Color

**Use project design tokens from `autoloads/design_tokens.gd`:**

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0F0F1A (COLOR_BACKGROUND_DARK) | Background, surfaces |
| Secondary (30%) | #1A1A2E (COLOR_SURFACE_DARK) | Cards, file sections |
| Accent (10%) | #22C55E (COLOR_SUCCESS) | Covered lines (green highlighting) |
| Destructive | #EF4444 (COLOR_ERROR) | Uncovered lines (red highlighting), coverage below threshold |

**Semantic colors for coverage reports:**
- Covered lines: `COLOR_SUCCESS` (#22C55E) - green background
- Uncovered lines: `COLOR_ERROR` (#EF4444) - red background
- Coverage above 80%: `COLOR_SUCCESS` - green badge
- Coverage 50-80%: `COLOR_WARNING` (#F59E0B) - yellow badge
- Coverage below 50%: `COLOR_ERROR` - red badge

**Source:** Pre-populated from existing `autoloads/design_tokens.gd` (lines 25-43, 48-67)

**Accent reserved for:** Coverage indicator badges and line highlighting in HTML reports

## HTML Coverage Report Specifications

### Report Structure
```html
<!DOCTYPE html>
<html>
<head>
    <title>Godot Coverage Report</title>
    <style>
        body { font-family: Arial, sans-serif; background: #0F0F1A; color: #F8FAFC; margin: 20px; }
        .covered { background-color: #22C55E; }
        .uncovered { background-color: #EF4444; }
        .line { padding: 2px 5px; font-family: monospace; font-size: 12px; }
        .file-section { margin-bottom: 30px; }
        .file-header { font-weight: bold; margin-bottom: 10px; font-size: 18px; }
        .percentage { font-size: 14px; color: #94A3B8; }
        .badge { padding: 4px 8px; border-radius: 4px; font-size: 12px; font-weight: bold; }
        .badge-success { background: #22C55E; color: white; }
        .badge-warning { background: #F59E0B; color: white; }
        .badge-error { background: #EF4444; color: white; }
    </style>
</head>
<body>
    <h1>Godot Coverage Report</h1>
    <!-- File coverage sections -->
</body>
</html>
```

### File Coverage Section
```html
<div class="file-section">
    <div class="file-header">
        autoloads/combat_manager.gd
        <span class="badge badge-success">75%</span>
        <span class="percentage">(120/160 lines covered)</span>
    </div>
    <!-- Line-by-line coverage display -->
</div>
```

### Line Display Format
```html
<div class="line covered">42: var damage = calculate_base_damage(attacker)</div>
<div class="line uncovered">43: # TODO: Apply elemental bonuses</div>
```

### Interactive Features
- **Clickable line numbers:** Anchor links to source file locations (if source viewer available)
- **Filter by coverage:** Toggle to show only uncovered lines
- **Sort by percentage:** Display files sorted from lowest to highest coverage
- **Search by filename:** Filter specific autoload scripts
