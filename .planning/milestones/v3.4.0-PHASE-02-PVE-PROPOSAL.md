# v3.4.0 Phase 02 Proposal: PvE Campaign System

**Status:** Ready for execution  
**Replaces:** Original Phase 02 (Matchmaking)  
**Duration:** 4-5 days  
**Dependency:** Phase 01 ✅ (autoload managers established)

---

## Goal

Implement **fully playable PvE campaign** with enemy encounters, dynamic loot drops, and progression tracking. Focus on core gameplay loop: explore → fight → loot → upgrade → repeat.

**Success Criteria:**
- ✅ Campaign map shows 8-10 encounters with difficulty scaling
- ✅ Enemy spawning + turn-based combat (uses existing combat_menu.gd)
- ✅ Loot drops on victory (gear + XP + gold)
- ✅ Inventory auto-updates with drops
- ✅ Player can equip new gear + return to campaign
- ✅ Headless validation: 5-encounter run with no crashes

---

## Why PvE First?

**vs. PvP Matchmaking:**
- ✅ No real-time sync complexity (turn-based = simpler)
- ✅ Testable offline (no Nakama multiplayer needed)
- ✅ More fun to demo (progression feels rewarding)
- ✅ Gates single-player v4.0 release
- ✅ Skill-based (player gets better via gear)

**AI Tactics (per difficulty):**

## End-to-End Campaign Flow

```
1. Player opens campaign_map.tscn
   ↓
2. See 8 encounters (some locked by difficulty)
   ↓
3. Click "Forest Goblin" (Difficulty 1)
   ↓
4. CampaignManager.start_encounter("forest_01")
   ↓
5. Transition to combat_menu.tscn
   ↓
6. EnemyAIManager spawns: Goblin (30 HP, 8 ATK, 2 DEF)
   ↓
7. Turn-based combat loop:
   - Player: Aim + Shoot
   - Combat calc: Player ATK - Enemy DEF = damage
   - Enemy health -= damage
   - Enemy AI decides move (random attack / defend)
   - Player health updated
   ↓
8. Player wins (Enemy HP = 0)
   ↓
9. LootManager.generate_loot("forest_01", difficulty: 1)
   ↓
10. game_over.gd shows loot screen:
    - "You defeated Forest Goblin!"
    - Rewards: +50 XP, +25 Gold, +1 Common Sword
    ↓
11. Player clicks "Continue" or "Equip Now"
    ↓
12. InventoryManager.receive_loot(loot)
    ↓
13. Return to campaign_map
    ↓
14. "Forest Goblin" now marked COMPLETED
    ↓
15. Next difficulty unlocks (if all Difficulty 1 complete)
```

## Comparison: PvE vs. PvP Matchmaking

| Aspect | PvE | PvP |
|--------|-----|-----|
| **Complexity** | Medium (AI logic) | High (real-time sync) |
| **Testing** | Headless offline | Needs Nakama mock |
| **Demo-friendly** | ✅ Fun progression | ❌ Slow without opponent |
| **Fun factor** | ✅ Satisfying loot loops | ✅ Competitive |
| **Dev time** | 4-5 days | 5-7 days |
| **Risk** | Low (no multiplayer) | Medium (sync bugs) |
| **v4.0 gate** | YES (single-player) | NO (multiplayer) |

**Decision:** PvE Phase 02 unblocks v4.0 shipping faster. PvP can be Phase 03.
