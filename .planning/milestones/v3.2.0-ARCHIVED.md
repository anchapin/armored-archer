### Phase 05: Project Settings & Import Pipeline

**Goal**: Configure Godot project for pixel-perfect rendering with proper import pipeline
**Depends on**: Nothing (first phase)
**Plans**: 3 plans

**Plans:**

- [x] 05-01: Viewport stretch settings — Configure 640x360 viewport with canvas_items stretch mode and integer scaling
- [x] 05-02: Pixel art import settings — Document Lossless compression, no mipmaps for sprites
- [x] 05-03: Sprite folder structure — Create characters/, enemies/, equipment/, ui/, backgrounds/ folders

**Details:**
- Viewport resolution: 640x360 (low-res for pixel art)
- Stretch mode: canvas_items (prevents texture blur)
- Scale mode: integer (whole-number scaling only)
- Aspect mode: expand (maintains aspect ratio on any display)
- Folder hierarchy: type-based organization for all asset types
