# Plan: 01-02 Particle Pool Implementation

**Phase:** 01 - Particle Effects Foundation
**Plan ID:** 01-02
**Objective:** Implement object pool for GPUParticles2D nodes with mobile optimization

## Tasks

### Task 1: Extend ObjectPool for particles
- **Action:** Create ParticlePool helper that extends ObjectPool.gd for GPUParticles2D:
  - Pre-instantiate particle scenes at startup
  - Configure pool size limits per effect type (max 20 per type)
  - Add acquire/release methods for particles
- **Verify:** Particles acquired from pool, returned after emission
- **Done:** ParticlePool class integrated with EffectsManager

### Task 2: Configure particle scene pre-instantiation
- **Action:** Load particle scenes (arrow_trail, combat_hit, enemy_death) at startup
- **Verify:** Scenes load without errors, GPUParticles2D configured
- **Done:** Pre-instantiated particles available in pool

### Task 3: Mobile optimization
- **Action:** Implement particle throttling:
  - Cap active particles per type to prevent overload
  - Skip emission if pool exhausted or throttled
  - Add debug logging for dropped effects (optional)
- **Verify:** No frame drops during heavy particle activity
- **Done:** Mobile performance optimized
