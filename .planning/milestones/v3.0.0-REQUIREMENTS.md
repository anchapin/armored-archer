## v3.0.0 Requirements

### Interface (UI) Requirements

- [x] **UI-01**: Theme Foundation — Create central Theme resource with Gilded Quest color tokens
- [x] **UI-02**: Typography System — Implement Plus Jakarta Sans (display) and Be Vietnam Pro (body)
- [x] **UI-03**: Button Components — Create bubbly tactile buttons with proper states
- [x] **UI-04**: No-Line Layout System — Replace borders with tonal layering
- [x] **UI-05**: Glassmorphism for Modals — Implement frosted glass shader for overlays
- [x] **UI-06**: Card Components — Create cards with intentional asymmetry

### Gameplay Requirements

- [x] **GAME-01**: Combat Particles — GPU-accelerated particles for hit, trail, and death effects
- [x] **GAME-02**: Hero Moment Effects — Screen-space post-processing shader with gold glow
- [x] **GAME-03**: Character Sprites — Sprite infrastructure with Gilded Quest palette
- [x] **GAME-04**: Atmospheric Backgrounds — Background presets with depth layers
