## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| 100% coverage target | Diminishing returns, wasted effort on low-risk code |
| Coverage without quality | Tests must have meaningful assertions, not just execute code |
| Testing private methods | Tests should validate public behavior, not implementation details |
| Godot line coverage instrumentation | No reliable tools exist for GDScript; pass rate proxy is documented approach |
| Coverage as sole metric | Test quality, flakiness, and performance matter alongside coverage |
| Mutation testing thresholds | Quality gates focus on coverage improvement first; mutation testing deferred to v3 |
| Complex coverage dashboards | HTML reports and trend scripts sufficient for 17%→60% improvement |
