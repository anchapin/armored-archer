**What's Done:**

The game loops are complete at the design level. Without backend connection, UI is non-functional. This milestone bridges the gap between art/design and live gameplay.

## Risk Analysis

| Risk | Mitigation | Impact |
|------|-----------|--------|
| Nakama RPC latency > 200ms | Use mock fixtures for local testing; profile on beta | Medium |
| Real-time sync race conditions | Implement optimistic updates + server authoritative reconcile | High |
| Inventory out-of-sync after equip | Transactional gear updates in Nakama storage | Medium |
| Combat log desync between players | Server sends canonical move sequence; client replays | High |
