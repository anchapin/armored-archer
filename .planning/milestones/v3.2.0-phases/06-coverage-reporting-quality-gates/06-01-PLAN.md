  <name>Task 2: Create Godot Coverage Calculation Script (Pass Rate Proxy)</name>
  <files>scripts/calculate_godot_coverage.py</files>
  <read_first>

    test/suites/player/test_player_stats_manager.gd
  </read_first>
  <action>
    Create scripts/calculate_godot_coverage.py with:

    1. Shebang: `#!/usr/bin/env python3`
    2. Import: `xml.etree.ElementTree`, `sys`, `json`
    3. Parse JUnit XML file from argument:
       ```python
       tree = ET.parse(sys.argv[1])
       root = tree.getroot()
       ```
    4. Calculate test pass rate as coverage proxy (Godot lacks line coverage tooling):
       ```python
       tests = root.findall('.//testcase')
       total = len(tests)
       failures = len(root.findall('.//failure'))
       errors = len(root.findall('.//error'))
       pass_rate = ((total - failures - errors) / total) * 100 if total > 0 else 0
       ```
    5. Count tests by subsystem:
       ```python
       subsystems = {}
       for test in tests:
           classname = test.get('classname', '')
           subsystem = classname.split('/')[0] if '/' in classname else 'unknown'
           subsystems[subsystem] = subsystems.get(subsystem, 0) + 1
       ```
    6. Output JSON to stdout:
       ```python
       json.dump({
           'pass_rate': pass_rate,
           'total_tests': total,
           'failures': failures,
           'errors': errors,
           'subsystems': subsystems
       }, sys.stdout)
       ```
    7. Make script executable: `chmod +x scripts/calculate_godot_coverage.py`

    Note: This uses pass rate as a coverage proxy because GDScript/Godot does not provide line coverage instrumentation. This is documented as acceptable in REQUIREMENTS.md.
  </action>

    <automated>test -x scripts/calculate_godot_coverage.py && python3 -c "import sys; sys.argv=['', '--help']; exec(open('scripts/calculate_godot_coverage.py').read().replace('ET.parse', 'exit'))" 2>/dev/null || true</automated>

  <action>
    Create scripts/track-coverage-history.sh with:

    1. Shebang: `#!/bin/bash`
    2. Set: `set -e`
    3. Create data directory: `mkdir -p data`
    4. Get current coverage from Go:
       ```bash
       cd backend
       go test -coverprofile=coverage.out -covermode=atomic ./... > /dev/null 2>&1
       COVERAGE=$(go tool cover -func=coverage.out | grep total | awk '{print $3}' | sed 's/%//')
       CRITICAL=$(go tool cover -func=coverage.out | grep -E "combat|matchmaking|rpg" | awk '{sum+=$3; n++} END {printf "%.1f", n>0 ? sum/n : 0}')
       cd ..
       ```
    5. Get git info:
       ```bash
       COMMIT=$(git rev-parse --short HEAD)
       BRANCH=$(git rev-parse --abbrev-ref HEAD)
       DATE=$(date -u +%Y-%m-%dT%H:%M:%SZ)
       ```
    6. Update or create data/coverage-history.json:
       ```bash
       if [ -f data/coverage-history.json ]; then
           # Append to existing array
           tmp=$(mktemp)
           jq --arg commit "$COMMIT" \
              --arg branch "$BRANCH" \
              --arg date "$DATE" \
              --arg cov "$COVERAGE" \
              --arg crit "$CRITICAL" \
              '.history += [{commit: $commit, branch: $branch, date: $date, overall: ($cov | tonumber), critical: ($crit | tonumber)}]' \
              data/coverage-history.json > "$tmp"
           mv "$tmp" data/coverage-history.json
       else
           # Create new file
           cat > data/coverage-history.json << EOF
       {
         "history": [
           {
             "commit": "$COMMIT",
             "branch": "$BRANCH",
             "date": "$DATE",
             "overall": $COVERAGE,
             "critical": $CRITICAL
           }
         ]
       }
       EOF
       fi
       ```
    7. Output trend analysis (last 5 entries):
       ```bash
       echo "=== Coverage Trend (last 5 measurements) ==="
       jq -r '.history[-5:] | reverse[] | "\(.date): \(.overall)% overall, \(.critical)% critical (\(.commit))"' data/coverage-history.json
       ```
    8. Make script executable: `chmod +x scripts/track-coverage-history.sh`
