    3. Add the following shell logic after line 30 (after critical path output):

```bash
# Extract package-level coverage
echo ""
echo "=== Package-level Coverage ==="
go tool cover -func=coverage.out | grep -v "^total:" | awk '{
    # Extract package path from function name
    pkg = $2
    gsub(/\/[^\/]+$/, "", pkg)  # Remove function name, keep package
    coverage = $3
    gsub(/%/, "", coverage)

    # Track coverage per package
    pkg_count[pkg]++
    pkg_total[pkg] += coverage
} END {
    for (p in pkg_count) {
        avg = pkg_total[p] / pkg_count[p]
        printf "%s: %.1f%% (%d functions)\n", p, avg, pkg_count[p]
    }
}' | sort
```

    This adds a per-package breakdown showing which modules need the most testing work.
